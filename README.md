# Python Game

A 2D space shooter game developed using **Python** and **Pygame**.

The game includes player movement, shooting, enemies, scoring, sound effects, and different game states.

## Features

* Player movement
* Shooting system
* Enemy movement
* Score tracking
* Sound effects and background music
* Win and Game Over states
* Restart functionality

## Technologies

* Python
* Pygame

## Project Structure

* `spacegame.py` — Main game file
* `cfg.py` — Game configuration
* `modules/` — Game modules and utility functions
* `resources/` — Sound and audio files
* `demonstration/` — Game demonstration
* `requirements.txt` — Required Python packages

## How to Run

1. Clone the repository.
2. Install the required packages:
   `pip install -r requirements.txt`
3. Run the game:
   `python spacegame.py`
